# Predicting Malaria Outbreak Risk Using Climate and Satellite Data

**Author:** Joan Joshua

## Project Overview
This project predicts malaria outbreak risk using synthetic climate and satellite-derived environmental variables. It combines public health surveillance, remote sensing, and machine learning to estimate outbreak risk levels and support early intervention planning.

## Objectives
- Predict malaria outbreak risk (Low, Moderate, High)
- Analyze climate and environmental drivers of transmission
- Explore geospatial malaria vulnerability patterns
- Support proactive public health response

## Dataset Features
### Climate Variables
- Temperature
- Rainfall
- Humidity
- Soil Moisture

### Satellite / GIS Variables
- NDVI Vegetation Index
- Land Surface Temperature
- Elevation
- Distance to Water Bodies
- Flood Risk

### Public Health Variables
- Malaria Cases
- Outbreak Risk Category

## Methods
1. Synthetic Data Generation
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Machine Learning Prediction using Random Forest
5. Model Evaluation
6. Geospatial Risk Visualization

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- GeoPandas

## Expected Outputs
- Predictive malaria risk model
- Risk heatmaps and trends
- Feature importance analysis
- Public health insights
